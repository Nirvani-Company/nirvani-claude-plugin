# Getting help

| Need | Where |
| --- | --- |
| Set up, sign in, or use the connector | https://mcp.nirvani.ai/docs |
| Account, workspace access, or billing | support@nirvani.ai or https://mcp.nirvani.ai/support |
| Access to a workspace | Your Nirvani admin enables workspaces and adds members. |
| A bug in the plugin or skill | [Open a bug report](https://github.com/Nirvani-Company/nirvani-claude-plugin/issues/new?template=bug_report.yml) |
| A new capability | [Request a feature](https://github.com/Nirvani-Company/nirvani-claude-plugin/issues/new?template=feature_request.yml) |
| A security issue | Follow [SECURITY.md](SECURITY.md). Never in a public issue. |

When you report a problem, include your Claude client (Claude Code, web, desktop or mobile) and its version, the plugin version from `/plugin list`, the exact message you saw, and the time it happened with your timezone. Never paste access tokens, sign-in codes, or customer data.
